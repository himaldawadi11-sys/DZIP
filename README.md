 DZIP (Distraction Zipper)

DZIP is a Chrome extension designed to help you stay focused by getting rid of the little distractions that keep pulling you away from what you're actually trying to do.

 What does it do?

 Focus Mode

Turn on Focus Mode directly from the page, add the tasks you need to finish, and get to work. Once you're in, DZIP keeps you focused on those tasks.

 Task-Locked Exit

You can't simply turn Focus Mode off whenever you feel like it. You have to finish every task and provide typed proof of what you actually did before you can exit.

 Zip Picker

See something distracting on a page? Hover over it and DZIP will highlight it. Click it, and the element gets hidden behind a small **"Zipped. Click to unzip"** bar.

Zipped elements stay hidden even after you reload the page, and the settings are saved separately for each website.

 Isolate Mode

Sometimes you don't need the whole page — you just need one thing.

Isolate Mode lets you click on an element, such as a video or article, and hides everything else on the page so you can focus only on what you selected.

Files


manifest.json: Chrome MV3 extension manifest
content.js: Main extension logic
content.css: Styling for the zipped-element bar
popup.html: Toolbar popup interface
popup.js: Handles the Focus Mode toggle

 Installing DZIP

DZIP is currently set up to be installed as an unpacked Chrome extension for testing.

1. Clone this repository.
2. Open chrome://extensions in Chrome.
3. Turn on Developer mode in the top-right corner.
4. Click Load unpacked.
5. Select the DZIP project folder.
6. Open or refresh a webpage.

You should see a Start Focus button appear in the top-right corner of the page.

That's itpick your tasks, start focusing, and zip away the distractions.
